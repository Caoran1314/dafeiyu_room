# 大肥鱼房间

一个 3D 房间，她在里面按**时间 + 聊天状态**做不同的事。

## 状态

| 条件 | 状态 |
|---|---|
| 0–8 点 | 睡觉 |
| 8–19 点 | 电脑前 |
| 19–24 点 | 床上刷手机 |
| 你刚发消息 | 立刻拿手机 |
| 25 分钟没说话 | 回到按时段的默认 |

## 页面

3D 房间（浅色大理石、奶油沙发、深木橱柜、晨光窗）+
主体角色 + 左下角对话流 + 右上角心情条。

## 换成自己的模型

把 `.glb` 或 `.vrm` 放到 `pages/room/model/character.glb`，
页面会自动加载并挑 `idle / sleep / work / phone` 四类动画；
没有模型就用内置的卡通形象。

## 命令

`/房间` 查看当前状态。
